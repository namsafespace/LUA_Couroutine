CCS 2105 - LUA COROUTINE FUNCTIONS
====================================

1. coroutine.create(function)
-----------------------------
Creates a new coroutine.

Example:
local task = coroutine.create(function()
    print("Hello")
end)

The coroutine does not run until resume() is called.


2. coroutine.resume(co, ...)
----------------------------
Starts or continues a coroutine.

Example:
coroutine.resume(task)

Values after the coroutine object are passed into the coroutine.

It returns:
success, value1, value2, ...

success = true if the coroutine ran successfully.
success = false if an error occurred.


3. coroutine.yield(...)
------------------------
Pauses the running coroutine and gives control back to the scheduler.

Example:
local value = coroutine.yield("Waiting")

The yielded values are returned by coroutine.resume().

A later resume() can pass values back into the coroutine.


4. coroutine.status(co)
-----------------------
Returns the current state of a coroutine.

Main states:

"suspended" -> created but not running, or paused at yield()
"running"   -> currently executing
"normal"    -> another coroutine is running while this coroutine
               is waiting for it
"dead"      -> finished execution or terminated because of an error

For normal scheduling, the most important states are:
suspended, running and dead.


5. coroutine.wrap(function)
----------------------------
Creates a coroutine and returns a function that resumes it.

Example:
local task = coroutine.wrap(function()
    coroutine.yield("Hello")
end)

print(task())

It is simpler than create(), but it does not provide the same
explicit status checking through a coroutine object.


IMPORTANT resume() RULE
-----------------------
Never resume a coroutine whose status is "dead".

Use:

if coroutine.status(task) ~= "dead" then
    coroutine.resume(task)
end


TWO-WAY COMMUNICATION
---------------------
yield() can send information to the scheduler.

resume() can send information back into the coroutine.

Example:

local decision = coroutine.yield("Manual review")

Later:

coroutine.resume(task, "approve")

The coroutine receives "approve" as the result of the yield() call.
